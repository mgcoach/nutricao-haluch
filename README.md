# Nutrição Haluch Aprofundada

Material de estudo que funde os livros do Dudu Haluch em um único percurso aprofundado, enriquecido com artigos recuperados no PubMed.

**Ler online:** https://mgcoach.github.io/nutricao-haluch/

## Como funciona

- HTML, CSS e JS puros, sem dependências externas além das fontes do Google.
- Cada parte é um fragmento em `partes/pN.html`, carregado pela rota `#parte-N`.
- Calculadoras, glossário e marcação de progresso rodam no próprio navegador.
- PWA: instalável na tela de início e com service worker para leitura offline.

## Aviso

Material de estudo. Prescrição de dieta e de suplementos é atribuição do nutricionista; diagnóstico, exames e medicamentos são do médico.
